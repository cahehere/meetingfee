# 모임 회비 정산 모바일 앱(PWA) 기획서

## 한 줄 소개
모임이 끝난 뒤 여러 사람이 번갈아 낸 식사·교통·여가 비용을 휴대폰 하나로 정확하게 정산하는 앱이다.

## 화면 구성
아래 탭 3개를 사용한다.

- 참가자: 별칭 추가·삭제, 예제 모임 불러오기, 전체 비우기
- 지출: 항목, 낸 사람, 금액, 참여자 체크, 지출 목록
- 정산: 총 지출, 사람별 받기·보내기, 송금 안내, 결과 공유

## 계산 규칙
1. 각 지출은 선택한 참여자끼리만 나눈다.
2. 1인당 금액은 원 단위에서 내림한다.
3. 나머지 1원은 해당 지출의 결제자에게 더한다.
4. 잔액은 실제로 낸 금액에서 부담 금액을 뺀다.
5. 받을 금액이 큰 사람과 보낼 금액이 큰 사람을 짝지어 작은 금액만큼 송금한다.
6. 받을 금액 합계, 보낼 금액 합계, 송금 합계가 모두 같아야 한다.

## 개인정보와 저장
참가자는 별칭만 사용한다. 실명·전화번호·계좌번호는 받지 않는다. 기록은 localStorage로 휴대폰에만 저장한다. 서버·로그인·회원가입·외부 라이브러리는 사용하지 않는다.

## 설치와 오프라인
아이폰은 Safari에서 공유 → 홈 화면에 추가를 선택한다. 안드로이드는 Chrome 메뉴에서 앱 설치 또는 홈 화면에 추가를 선택한다. HTTPS 주소에서 앱을 한 번 열어 서비스 워커가 파일을 저장하면 인터넷 없이도 다시 열 수 있다.

## 테스트 체크리스트
- [ ] 120,000원을 4명이 나누면 30,000원씩이다.
- [ ] 40,000원을 3명이 나누면 13,333원·13,333원·13,334원이다.
- [ ] 참여하지 않은 사람에게 부담 금액이 생기지 않는다.
- [ ] 모든 잔액의 합이 0원이다.
- [ ] 송금 목록 적용 후 모든 잔액이 0원이다.
- [ ] 아이폰 Safari에서 홈 화면에 추가된다.
- [ ] 안드로이드 Chrome에서 설치된다.
- [ ] 인터넷을 끊어도 앱이 열린다.
- [ ] 저장한 기록이 다시 보인다.
- [ ] 공유 결과의 금액이 화면과 같다.

## 범위 밖
은행 송금, 계좌번호, 로그인, 회원가입, 서버 저장, 여러 휴대폰 동기화, 앱스토어 등록용 네이티브 앱은 만들지 않는다.
